LiSA – Configurazione IA (Gemini)

Questa guida ti spiega passo-passo come ottenere una chiave API di Gemini (Google AI), come inserirla nell'app LiSA e come risolvere i problemi più comuni. Segui attentamente tutti i passaggi per abilitare le funzioni di intelligenza artificiale (IA) e ricevere suggerimenti automatici, classificazione e ricette smart.

Importante

La chiave API è personale e privata. Non condividerla con altre persone e non pubblicarla online (GitHub, forum, screenshot, ecc.). Trattala come una password: chiunque la possieda può usarla a tuo nome e consumare il tuo credito. Se pensi che sia stata compromessa, revocala subito da Google AI Studio e creane una nuova.

1. Come ottenere la tua API Key Gemini

Prerequisiti
  • Un account Google attivo (Gmail va bene).
  • Accesso a Google AI Studio.
    (Potresti dover accettare i termini d’uso la prima volta che accedi.)
  1. Vai su https://aistudio.google.com/app/apikey e accedi con il tuo account Google.
  2. Se richiesto, accetta i termini di utilizzo di Google AI Studio.
  3. Premi il pulsante + Create API key (o Crea API key se l’interfaccia è in italiano).
  4. Dai un nome riconoscibile alla chiave (es: LiSA) e conferma.
  5. Copia la chiave generata (una lunga stringa di lettere e numeri).
    Attenzione: puoi vedere la chiave solo ora! Se la perdi, dovrai crearne una nuova.
Nota

Le API key Gemini sono gratuite per uso personale, ma Google può imporre limiti di utilizzo o richiedere una carta di credito per usi intensivi.

2. Come inserire la chiave nell’app LiSA

  1. Apri l’app LiSA normalmente.
  2. Vai nelle Impostazioni (icona ingranaggio in alto a destra).
  3. Nel campo Gemini API Key incolla la chiave che hai copiato da Google AI Studio.
  4. Premi Salva e Chiudi.
  5. Se la chiave è valida, le funzioni IA saranno subito attive (classificazione automatica, suggerimenti, ricette smart, ecc.).

3. Domande frequenti e risoluzione problemi

FAQ
  • La chiave non funziona o ricevo errori?
    - Controlla di aver copiato la chiave senza spazi.
    - Verifica di non aver superato i limiti di utilizzo gratuiti.
    - Se hai cambiato account Google, crea una nuova chiave.
    - Se la chiave è stata revocata, creane una nuova da Google AI Studio.
  • Posso usare la stessa chiave su più dispositivi?
    Sì, ma solo per uso personale. Non condividere la chiave con altri utenti.
  • Come posso eliminare o rigenerare una chiave?
    Vai su Google AI Studio, elimina la chiave vecchia e creane una nuova.
  • La chiave scade?
    No, ma Google può revocarla in caso di abuso o cambi di policy.

4. Sicurezza e privacy

  • La tua chiave API resta solo sul tuo dispositivo e non viene inviata a terzi (tranne che a Google per le richieste IA).
  • LiSA non salva né trasmette le tue chiavi su server esterni.
  • Puoi cancellare la chiave in qualsiasi momento dalle impostazioni dell’app.
Attenzione

Se condividi screenshot o video dell’app, nascondi sempre la tua API key!
