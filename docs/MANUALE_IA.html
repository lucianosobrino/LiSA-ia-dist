🧠 Guida Dettagliata Configurazione IA

L'integrazione con l'Intelligenza Artificiale (Google Gemini) trasforma LiSA da una semplice lista della spesa a un assistente personale evoluto.

1. Come ottenere la Chiave API Google (Passo dopo Passo)

La chiave API è gratuita per uso personale (entro i limiti di utilizzo di Google) e serve a LiSA per comunicare con i modelli Gemini.

  1. Accedi a Google AI Studio: Vai sul sito aistudio.google.com.
  2. Login: Effettua l'accesso con il tuo account Google (Gmail).
  3. Crea Chiave: Nel menù a sinistra, clicca sul pulsante "Get API key".
  4. Generazione: Clicca su "Create API key in new project". Se hai già dei progetti Google Cloud, puoi selezionarne uno esistente.
  5. Copia: Una volta generata, vedrai una stringa alfanumerica (la tua chiave). Clicca su "Copy" per copiarla negli appunti.
  6. Configurazione in LiSA: Apri LiSA, tocca l'icona dell'omino (Account) -> Chiavi Personali. Tieni premuto nel campo "Gemini API key" e seleziona Incolla, oppure usa il tasto "Incolla" se disponibile.
  7. Attivazione: Torna nelle Impostazioni e assicurati che il toggle "Intelligenza Artificiale" sia attivo.
Nota di Sicurezza: La tua chiave API viene salvata esclusivamente sul tuo dispositivo. Non condividerla mai con nessuno.
